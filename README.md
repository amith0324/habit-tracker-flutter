# Habit Tracker App (Flutter)

A clean and minimal **Habit Tracker application built with Flutter** that helps users build consistency through daily habit tracking, streaks, calendar view, and progress statistics.

---

## ✨ Features

- ✅ Add and manage daily habits  
- 🔥 Habit streak tracking (day-wise progress)
- 📅 Monthly calendar view to track completed days
- 📊 Weekly statistics & progress overview
- 🌙 Light & Dark mode support
- 💾 Local data persistence (data remains after app restart)
- 🎨 Clean and user-friendly UI

---

## 🛠️ Tech Stack

- **Flutter**
- **Dart**
- **SharedPreferences** (for local storage)
- **Material UI**

---

## 📱 Supported Platforms

- Android  
- Web  
- macOS (desktop)

---
